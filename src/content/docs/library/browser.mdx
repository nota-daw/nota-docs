The browser on the left of the main window holds everything you can bring into a project. Its
tabs are the icons down its left edge; the button at the bottom collapses it (also **View ▸ Toggle
browser**).

<Shot id="start-here/browser-instruments" alt="The browser, Instruments tab" width={300} />

## Tabs

| Tab | What's in it |
|---|---|
| **Instruments** | Nota's instruments (**Built-in**) and your plug-in instruments (**Plug-ins**). Each device opens into folders of its factory presets — Pads, Bass, Leads, Keys & Plucks… — with **Init** on top |
| **Audio effects** | Built-in and plug-in effects, with their presets — Vocals, Drums, Mix & Bus, Mastering… |
| **MIDI effects** | Arpeggiator, chord, scale, length, velocity, random, with their presets |
| **Files** | Your sample library as a folder tree — see [Smart samples](../smart-samples/) |
| **Presets** | The presets you saved yourself (right-click a device header ▸ **Save preset**). Right-click one to reveal it or **Delete…** it (to the Trash); right-click a folder row to open the presets folder |
| **Projects** | The projects in your projects folder — open, reveal (**Reveal in Finder** on macOS, **Show in Explorer** on Windows, **Show in file manager** on Linux) or delete |
| **MIDI map** | Every control mapped to a controller, gamepad or phone — see [MIDI Learn](../../control/midi-learn/) |
| **History** | The open project's [versions](../../basics/version-history/) |
| **Track inspector** | The selected track's settings in one place — see below |

## Track inspector

The last icon on the rail, set apart by a hairline, opens the **Track inspector**. It shows the
track the Devices panel shows: select a track and it follows. With nothing selected it reads
**No track selected**. It gathers what you would otherwise reach from the track's right-click
menu; the menu keeps all its entries.

<Shot id="library/track-inspector-tab" alt="The Track inspector tab with the Texture audio track selected" width={300} />

| Section | What it does |
|---|---|
| **Name** | Type to rename; <Kbd>Enter</Kbd> or clicking away keeps it, <Kbd>Esc</Kbd> puts the old name back. An empty name returns the track to its automatic one |
| **Mute**, **Solo**, **Arm** | The header's buttons. A return has only **Mute**; a group has **Mute** and **Solo** |
| **Input** | On an audio track, **Record input** (a hardware input, the master, another track or a return) and **Monitor input** (**On** / **Off**; not available while the master is the input). On an instrument track, **MIDI from** |
| **Color** | The track palette — nine families in a base, a light and a dark shade — and **Auto** |
| **Height** | **Compact**, **Standard** or **Large**. Not shown for a return |
| **Freeze** | The track menu's freeze commands as buttons — **Freeze track**, **Live freeze**, **Unfreeze track**, **Flatten to audio track**, and on a live-freeze link **Edit source**, **Done — re-freeze**, **Discard edits** and **Flatten (remove source)**. Audio and instrument tracks only |

Every control does what the header and the menu do, so undo, exclusive arming and the
master-can't-be-monitored rule behave the same. The tab picks up changes made anywhere else — the
header, the menu, undo — within a moment. A return shows its name, **Mute** and colour; the
master shows only its name. Volume, pan, sends and output stay in the track header and the
[Mixer](../../views/mixer/). The tab has no search box.

## Searching

The search box filters the tab and counts the matches. It is one box for every tab: switch tabs
and the new tab is filtered by what the box says. Search opens the preset folders around the
hits, and a folder name ("Mastering") lists that folder across every device. The status line at the
bottom counts what's shown — `16 built-in · 0 plug-ins`.

**Category chips** sit above the list on the **Instruments**, **Audio effects** and **MIDI
effects** tabs — **Synths**, **Drums**, **Samplers**…; **EQ & filter**, **Dynamics**, **Reverb &
delay**, **Modulation**…; **Generate** and **Shape**. Click one to see only that kind of device,
click it again to see everything. Each tab keeps its own pick, and the chips combine with search,
favourites and tags. Your plug-ins join the same categories by the category they report; anything
Nota doesn't recognise goes under **Other**.

The ⋮ button beside the search box holds view options — type tags, category chips, grouping by
source, favourites first — and the tag editor.

## Favourites and tags

With grouping by source on, the **Built-in** and **Plug-ins** headers fold: click one to collapse
its section, click again to open it.

Star (★) a device or preset to make it a favourite — favourites sort to the top of their section.
**Tags** let you group things your own way: assign them from the right-click menu, edit their title and
colour in the tag editor, and filter with the chips under the search box.

## Getting things into the project

| Do this | To |
|---|---|
| Double-click an instrument | Swap it onto the selected instrument track (its clips and effects stay); with no instrument track selected, a new track with it and an empty one-bar clip |
| ⌥ + double-click an instrument | Always a new track with it |
| Double-click an effect | Add it to the selected track |
| Double-click a MIDI file | Put it on a new track |
| Drag onto a track or empty space | Add the instrument, effect, sample or loop there |
| Drag onto a device chain | Insert the effect between cards (a bar marks the spot) or replace the card under the pointer |
| Drag onto a Session slot | Put a sample or MIDI file in that slot |
| Drag onto a rack chain or a pad | Load it there |

Effects and presets can also be dropped onto a return track or the master.

An instrument preset dropped onto an instrument track loads into that track's instrument — it
switches the instrument if the preset is for a different one, and the track's effects stay. Dropped
on empty space, it starts a new track. Whatever you drop, the track it lands on becomes the
selected one, a newly created track included.

## Hearing before loading

The **preview player** at the bottom of the browser plays samples, presets, kits and devices before
you load them — see [Preview player](../preview-player/).
