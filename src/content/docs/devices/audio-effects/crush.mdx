Nota Crush lowers the bit depth and the sample rate: old samplers, game consoles, broken radios,
digital destruction.

<Shot id="devices/audio-effects/crush/card" alt="Nota Crush, Quantiser tab with the held and quantised steps" />

**Signal flow:** drive → anti-alias filter → sample & hold (with jitter) → dither → shape → quantise
→ noise floor → post filter → DC filter → mix → auto gain.

## The graphs

| Tab | What it shows (and what you can drag) |
|---|---|
| **Quantiser** | The held, quantised steps over a sine — drag up / down for **Bits**, left / right for **Rate** |
| **Spectrum** | The output spectrum, what the crush added, and the images above the reduced Nyquist — drag the Nyquist and filter lines |
| **Transfer** | The transfer curve — drag for **Drive** |

<Shot id="devices/audio-effects/crush/spectrum" alt="Nota Crush, Spectrum tab" />

## Controls

| Control | What it does |
|---|---|
| **Mode** | **Digital** (hard truncation), **Analog** (soft clip) or **Fold** (wavefolding) |
| **Bits** · **Rate** | Bit depth and the reduced sample rate |
| **Drive** | Input drive |
| **Anti-alias** | Filters what the reduced rate would fold back — on for smooth, off for harsh aliasing |
| **Dither** · **Jitter** · **Noise** | Grit: dither noise, clock jitter, a noise floor |
| **Filter** | A post low-pass to tame the top |
| **DC filter** | Removes any DC offset |
| **Wet** · **Gain** · auto gain | Dry / wet, output, and riding the output back to the input's loudness |
