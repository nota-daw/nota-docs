Nota Random adds controlled chance: a drummer who's a little loose, ghost notes that come and go, a
melody that wanders, hats that thin out. It's reproducible — lock the seed and the same variation
plays every time.

<Shot id="devices/midi-effects/random/card" alt="Nota Random: what varies, the output bar and the dice" />

## What varies

| Dimension | Range |
|---|---|
| **Note** | ± semitones |
| **Velocity** | ±64 |
| **Timing** | 0–100 ms late (a real-time effect can only delay) |
| **Skip** | Drop the note |
| **Octave** | ±2 octaves |

## Dice

| Control | What it does |
|---|---|
| **Chance** | How likely a note is varied at all |
| **Distribution** | **Gauss** (a bell — small changes more often), **Even** (flat) or **Walk** (drifts from note to note) |
| **Per note** / **Per bar** | Draw for each note, or once for the bar |
| **Seed** · **Reroll** | The roll's seed; reroll for a new one |
| **Lock** | Hold the bar showing and repeat it every bar |
| **Stay in scale** | Snap varied pitches into C major |

The **Output** window shows one bar of demo notes — input dashed, output filled (brighter =
louder, a link when the pitch moved, × when skipped). Every bar is a fresh roll until you lock it.

## Presets

32 factory presets: humanising (**Human Touch**, **Loose Drummer**, **Tight Humanize**, **Lazy
Behind**, **Velocity Shimmer**, **Accent Lottery**), sparseness (**Ghost Notes**, **Sparse Hats**,
**Thin Out**, **Stutter Drop**), pitch (**Pitch Roulette**, **Gentle Wander**, **Melodic Drift**, **Wide
Leaps**, **Chromatic Smear**, …) and more.
