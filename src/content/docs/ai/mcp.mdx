Nota has a built-in **MCP server** (Model Context Protocol). With it on, an AI assistant — Claude
Desktop or Claude Code — can read and edit the project open in Nota: add tracks, write notes, set up
devices, build Session scenes, mix and export. Every change it makes appears on screen immediately
and goes through undo, like your own.

## Turning it on

<Steps>

1. **Settings ▸ Appearance ▸ AI control (MCP)** ▸ **Enable MCP server (let an AI drive Nota)**. It's off
   by default.

2. **Copy config** copies a ready-made server entry; add it (or the URL) as an MCP server in Claude
   Desktop or Claude Code.

3. Ask the assistant to work on your project.

</Steps>

<Shot id="preferences/appearance" alt="Settings ▸ Appearance with the AI control (MCP) section" />

The server listens only on your own computer (`127.0.0.1`, port 3900 by default) — nothing on the
network can reach it.

## What an AI can do

- **Transport and project** — play, stop, tempo, signature, loop, metronome, a full snapshot of the
  project, the arrangement's sections (`list_sections` and `set_sections` carry an `automatic` flag
  for "Section N" names), and its version history (list, save with a note, switch, name
  and star).
- **Tracks and mixer** — add and remove tracks, volume, pan, mute, solo, groups, sends and returns,
  meters.
- **Notes and clips** — MIDI clips, notes and their controller curves (sustain pedal, wheels, any
  CC), automation lanes and points.
- **Devices** — instruments, effects and MIDI effects by kind, their parameters, presets (factory and
  your own), racks and their chains, zones and macros, Drum Rack pads, Nota Rhythm patterns.
- **Plug-ins** — list, add, open the editor, read and write parameters and state.
- **Session** — the whole clip launcher: slots, clips, scenes, launching, follow actions, recording.
- **Samples** — search the library by kind, tempo, key and name, find similar sounds, load samples.
- **AI features** — Separate Stems and Convert to MIDI on a clip.
- **Export** — the master or stems to WAV, FLAC or MP3 (`format`, `bitrateKbps` for MP3,
  `startBeat` to start the render later in the song).
- **MIDI** — list inputs and work with MIDI Learn mappings.
- **Themes** — read, check, preview, save and wear colour themes, so an assistant can design one
  with you. See [Design a theme](#design-a-theme).

<Aside>
Some things stay yours: an AI can't delete versions or install models.
</Aside>

## Design a theme

Give an assistant a palette — a few colours, a photo's mood, "like an old mixing desk" — and it
can turn it into a full [theme of your own](../../preferences/appearance/#your-own-themes), check
that it stays readable and show you how it looks before anything changes on your screen.

<Steps>

1. It reads a built-in theme as a template (`get_theme`) and what each colour is for
   (`get_theme_catalogue`), and the fonts installed on your computer (`list_system_fonts`).

2. It writes its version and checks it (`validate_theme`): every problem with the key it is
   about, and every readability warning with the contrast it measured.

3. It renders previews (`preview_theme`): one picture for each part of Nota — the whole
   window, the top bar, the arrangement, the mixer, a device rack, the piano roll, the browser,
   Settings, a menu and a dialog — from a fixed sample project, off screen. Your window doesn't
   change. By default the pictures wear your [accent colour](../../preferences/appearance/#accent-colour),
   as the theme really would; it can ask for the theme's own accent instead.

4. When you want to see it for real, it puts it on (`try_on_theme`): Nota wears the theme
   without saving it, until it takes it off (`revert_try_on`), you pick a theme in Settings, or
   Nota restarts.

5. It saves the theme into your themes folder (`save_theme`) — the card appears in
   Appearance at once — and wears it (`apply_theme`), exactly as if you had clicked the card.

</Steps>

An assistant can't overwrite a built-in theme, and replaces one of your own only when it says
so. It can also list your themes (`list_themes`) with the files that failed to load and why,
so it can help fix a theme you wrote by hand. The file format is on
[Theme files](../../reference/theme-files/).

An assistant can also switch the [look](../../preferences/appearance/#classic-look) (`set_look`:
`new` or `classic`), exactly as the switch in Appearance does. It can render previews in either
look (`preview_theme` with `look`) and read a built-in theme in its classic colours (`get_theme`
with `look: classic`) as the start for a classic theme of your own. `list_themes` tells it which
look you wear.
