| Molette sur la chaîne d’appareils | Le faire défiler latéralement · sur la poignée d’une bande d’EQ, la molette règle son Q ; sur une case de valeur, elle change la valeur par pas |
| Glisser un bouton rotatif | Changer une valeur d’appareil · maintenir ⌘ ou ⇧ pour des pas fins |
| Glisser un curseur | Gauche / droite (ou haut / bas) change la valeur · maintenir ⌘ ou ⇧ pour des pas fins |
| ⌥-clic sur un bouton rotatif, un fader ou un curseur | Saisir une valeur (les unités comme k, ms, dB, L / R fonctionnent) · un double-clic sur sa valeur fait de même |
| Return · Esc · Tab / ⇧Tab (saisie d’une valeur) | La valider · annuler · la valider et saisir la valeur suivante / précédente de la carte |
| ⌥-clic sur une poignée de graphique, un nœud d’enveloppe ou une cellule de la matrice de modulation | Saisir ses valeurs : un nœud qui en a plusieurs (fréquence · gain · Q, déclin · maintien) utilise Tab pour passer de l’une à l’autre |
| Double-clic sur un bouton rotatif, un fader ou un curseur | Remettre la valeur par défaut |
| Double-clic sur une cellule de la matrice de modulation | Effacer la route (Volt, Aurora) · retirer le câble (Consort) |
| Clic droit sur un bouton rotatif, un fader ou un curseur | Saisir une valeur… · Rétablir la valeur par défaut |
| Glisser jack → jack | Brancher un câble dans Nota Consort · ⌥-clic sur un jack pour retirer ses câbles |
| Clic · ⇧ · ⌥ sur un pas Rhythm | Pas activé / désactivé · accent · pas doux — glisser pour peindre, haut / bas (ou défilement) pour sa vélocité |
| Clic sur une voix Rhythm | La sélectionner et la jouer · y déposer un fichier pour charger un échantillon |
