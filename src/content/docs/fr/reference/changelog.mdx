Nota publie une nouvelle version à peu près chaque semaine. Chacune liste ses changements de trois façons :

- **Dans l’application** : après une mise à jour, **Nouveautés** montre les notes de version de chaque version depuis
  la vôtre (le même texte que sur GitHub) ; ouvrez-le à tout moment depuis **Aide ▸ Nouveautés**.
- **Sur GitHub** : chaque version, avec ses notes et ses téléchargements.
- **Dans le code source** : tout l’historique dans `CHANGELOG.md`.
