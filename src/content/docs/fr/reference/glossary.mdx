**Action de suivi** : ce qu’un clip ou une scène de Session fait après avoir joué un moment.

**Appareil** : un instrument, un effet audio ou un effet MIDI. Voir [Appareils](../../devices/).

**Armer** : préparer une piste à enregistrer (le **●** dans son en-tête).

**Arrangement** : la vue qui étale le morceau sur une timeline. Voir [Arrangement](../../views/arrangement/).

**AU / VST3** : les formats de plug-ins que Nota héberge : VST3 partout, AU sous macOS. Voir [Plug-ins](../../plugins/).

**Automation** : une valeur qui change dans le temps, dessinée ou enregistrée dans une voie. Voir [Automation](../../editing/automation/).

**Boucle / one-shot** : un échantillon qui se répète dans le temps, par opposition à un coup unique.

**Chaîne** : les appareils d’une piste, ou un brin à l’intérieur d’un rack, traités de gauche à droite.

**Clip** : un bloc de notes (clip MIDI) ou d’audio (clip audio) sur une piste ou dans un emplacement de Session.

**Consolider** : fusionner le matériel d’une plage en un clip par piste.

**CV** : un signal de commande de la vue Modular qui fait bouger un paramètre. Voir [Modular](../../views/modular/).

**Décompte** : des mesures de clics avant que la lecture ou l’enregistrement ne démarre.

**Écoute** : entendre l’entrée d’une piste en direct à travers ses effets.

**Emplacement** : une cellule de la grille de Session.

**Geler / Aplatir** : rendre une piste en audio pour économiser du processeur ; aplatir rend cela définitif.

**Groupe** : une piste qui contient d’autres pistes et leur sert de sous-mixage.

**Groupe de coupure** : des pads qui se coupent mutuellement, comme un charleston ouvert et un charleston fermé.

**Kit** : un ensemble de sons de batterie chargé sur un Drum Rack ou Nota Rhythm.

**Legato** : jouer une nouvelle note avant de relâcher la précédente ; les synthés peuvent glisser au lieu de redéclencher.

**LUFS** : le volume perçu, tel que le mesurent les services de streaming.

**Macro** : un bouton sur un rack ou un kit qui pilote beaucoup de paramètres à la fois. Voir [Macros](../../devices/racks/macros/).

**Master** : la somme de toutes les pistes, qui part vers vos enceintes.

**MCP** : le protocole qu’un assistant IA utilise pour travailler dans Nota. Voir [Pilotage par IA via MCP](../../ai/mcp/).

**MIDI Learn** : associer une commande matérielle ou de téléphone à une commande de Nota. Voir [MIDI Learn](../../control/midi-learn/).

**Modulateur** : un LFO, une enveloppe ou une source semblable qui fait bouger des paramètres dans le temps.

**Panneau de détail** : le panneau sous la vue qui montre des appareils, un motif pas à pas ou un clip.

**PDC** : la compensation du retard des plug-ins : Nota retarde les autres pistes pour que tout reste en mesure.

**Piste audio** : une piste qui contient des clips audio et n’a pas d’instrument.

**Piste de retour** : un bus d’effet partagé que les pistes alimentent par leurs **envois**.

**Plage de temps** : une étendue de temps à travers les pistes, sélectionnée avec ⇧-glisser.

**Préréglage** : des réglages enregistrés pour un appareil. Les préréglages d’usine sont fournis avec Nota ; vous pouvez enregistrer les vôtres.

**Quantification de lancement** : la grille sur laquelle démarrent les clips et les scènes de Session (Quant).

**Quantifier** : accrocher les notes à la grille.

**Rack** : un appareil qui contient plusieurs chaînes : Instrument Rack, Drum Rack, Audio Effect Rack.

**Scène** : une ligne de la vue Session, lancée d’un seul bloc.

**Section** : une étendue nommée du morceau dans la voie Sections de l’Arrangement. À moins que vous ne la renommiez, son nom est automatique : **Section N** selon sa place dans le morceau.

**Session** : la vue de lancement de clips. Voir [Session](../../views/session/).

**Sidechain** : envoyer le signal d’une piste à un appareil d’une autre piste pour le contrôler.

**Stem** : une partie d’un mixage seule (batterie, basse, voix…), issue d’un export ou de Séparer les stems.

**Tonalité du projet** : la tonalité réglée dans la barre de transport ; les boucles peuvent y être transposées.

**Unison** : plusieurs copies désaccordées de chaque voix, pour de la largeur.

**Vélocité** : la force avec laquelle une note est jouée.

**Version** : un état enregistré du projet dans son historique. Voir [Historique des versions](../../basics/version-history/).

**Vrai pic** : le niveau le plus élevé entre les échantillons, qu’un convertisseur peut réellement atteindre.

**Warp** : étirer l’audio sur le tempo du projet sans changer sa hauteur.

**Zone** : la plage de notes ou de vélocité à laquelle répond une chaîne de rack.
