- **Utiliser une manette connectée pour les notes et les commandes assignées** : l’interrupteur général, désactivé par
  défaut.
- **Entrée manette** : les manettes connectées, avec la dernière commande pressée.
- **Disposition** : ce que jouent les boutons : boutons de face C4 D4 E4 F4, gâchettes G4 A4 B4 C5, croix haut / bas
  l’octave, gauche / droite la vélocité.

Les notes vont vers la piste d’instrument armée. L’entrée de manette n’existe que sous macOS dans cette version. Voir
[Manettes](../../control/gamepads/).
