## The start window

When Nota opens, the start window comes first. It is the quickest way back into what you
were working on.

<Shot id="start-here/start-window" alt="The Nota start window with New project, Open project and a list of recent projects" />

- **New project** — a [new project](../../basics/projects/#a-new-project) in the main window,
  with an instrument track, an audio track and **Reverb** / **Delay** returns ready.
- **Open project…** — pick a `.nota` project anywhere on disk.
- **Recent projects** — the projects you opened or saved lately, newest first, with when you
  last touched them. Click one to select it, double-click it (or select it and press
  <Kbd>Return</Kbd>) to open it. The arrow keys move through the list.
- **Show on startup** — turn the start window off if you'd rather go straight to a new
  project. **File ▸ New** (<Kbd>⌘ N</Kbd>) and **File ▸ Open…** (<Kbd>⌘ O</Kbd>) work the
  same from the main window.
- **Documentation**, **Settings** and **What's New** at the bottom open this manual (at
  [Your first track](../first-track/)) and those windows. Later, click the version number at the
  bottom right of the main window (or choose **Help ▸ What's New**) to read the release notes
  again.

To close the start window and keep the current project, press <Kbd>Esc</Kbd> or click the main
window behind it.

## When a new version is out

The start window also shows a banner when a new Nota is available: **Update** downloads it
with a progress bar and checks it against the release's checksum, **Release notes** opens the
release page, **Dismiss** hides the banner. Once it's downloaded, choose **Restart now** — or
**Later**, and it installs the next time you quit. The same update shows in the main window's
status bar too, so you don't miss it when the start window is off (see
[Updates](../install/#updates)).

## What's new

After an update, a **What's new** window shows the release notes of every version since the
one you had, once. They are the same notes as on the release page. You can bring them back any
time from **Help ▸ What's new** — or read the [changelog](../../reference/changelog/).

<Shot id="start-here/whats-new" alt="The What's new window with the release notes of Nota 0.55.1" width={460} />

**Help ▸ About Nota** shows the app and engine versions and the licence.

## If Nota didn't close properly

While you work, Nota keeps a recovery copy of the open project in the background (about every
30 seconds, and only when something changed). If Nota or your computer stops unexpectedly,
the next launch asks:

> Nota didn't shut down cleanly. Recover unsaved work from …?

**Recover** brings the project back as it was; **Discard** throws the recovery copy away.
The recovery copy is a safety net, not a save — save your project as usual
(<Kbd>⌘ S</Kbd>), see [Projects and saving](../../basics/projects/).

<Aside title="⌘ or Ctrl?">
This manual writes shortcuts the macOS way. On Windows and Linux, read <Kbd>⌘</Kbd> as
<Kbd>Ctrl</Kbd> and <Kbd>⌥</Kbd> as <Kbd>Alt</Kbd>.
</Aside>
