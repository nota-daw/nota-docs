Nota Crush понижает разрядность и частоту дискретизации: старые сэмплеры, игровые приставки,
сломанное радио, цифровое разрушение.

<Shot id="devices/audio-effects/crush/card" alt="Nota Crush, вкладка Quantiser со ступенями квантования" />

**Путь сигнала:** драйв → антиалиасинговый фильтр → выборка-хранение (с джиттером) → дизер →
форма → квантование → шумовой пол → фильтр после → DC-фильтр → микс → автокомпенсация.

## Графики

| Вкладка | Что показывает (и что можно тянуть) |
|---|---|
| **Quantiser** | Ступени выборки и квантования на синусе — вверх / вниз **Bits**, влево / вправо **Rate** |
| **Spectrum** | Спектр выхода, что добавил крашер, и зеркальные образы выше пониженного Найквиста — тяните линии Найквиста и фильтра |
| **Transfer** | Передаточная кривая — тяните для **Drive** |

<Shot id="devices/audio-effects/crush/spectrum" alt="Nota Crush, вкладка Spectrum" />

## Регуляторы

| Регулятор | Что делает |
|---|---|
| **Mode** | **Digital** (жёсткое усечение), **Analog** (мягкое ограничение) или **Fold** (wavefolding) |
| **Bits** · **Rate** | Разрядность и пониженная частота дискретизации |
| **Drive** | Входной драйв |
| **Anti-alias** | Убирает то, что пониженная частота завернула бы обратно, — вкл для гладкости, выкл для жёсткого алиасинга |
| **Dither** · **Jitter** · **Noise** | «Зерно»: шум дизера, дрожание такта, шумовой пол |
| **Filter** | ФНЧ после крашера, чтобы приручить верх |
| **DC filter** | Убирает постоянную составляющую |
| **Wet** · **Gain** · автокомпенсация | Dry / wet, выход и возврат громкости к уровню входа |

**West Coast Fold**, **Metal Fold**).
