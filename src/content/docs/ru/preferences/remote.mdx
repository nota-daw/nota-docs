| Настройка | Что делает |
|---|---|
| **Allow control from a phone** | Включает Nota Remote (по умолчанию выключено) |
| **Port** | Сетевой порт для телефонов (по умолчанию 7788) — если включён брандмауэр, разрешите его |
| **Status** | Где слушает Nota, включая USB-адрес, если телефон на кабеле |
| **Phones may** | **Play notes only** (пэды и клавиши) или **Play and control the project** (ещё микшер, транспорт, макросы, XY и Session) |

**Trusted devices** — телефоны, которые уже сопрягались. Доверенный телефон переподключается с иконки на
домашнем экране без кода; **Forget** отключает его, и ему придётся отсканировать новый код. Выключение
Remote отключает всех.

При включении macOS спросит, можно ли Nota искать устройства в локальной сети (Windows — можно ли
пользоваться сетью), — разрешите, иначе телефоны не достучатся. См. [Nota Remote](../../control/nota-remote/).
