- **Use a connected gamepad for notes and mapped controls** — главный переключатель, по умолчанию
  выключен.
- **Gamepad input** — подключённые геймпады с последним нажатым регулятором.
- **Layout** — что играют кнопки: лицевые — C4 D4 E4 F4, плечевые — G4 A4 B4 C5, крестовина вверх /
  вниз — октава, влево / вправо — velocity.

Ноты идут на подготовленный к записи трек инструмента. Ввод с геймпада в этой версии работает только
на macOS. См. [Геймпады](../../control/gamepads/).
