Одна страница для трёх видов загрузок, выбираемых переключателем рядом с заголовком:

| Раздел | Что там |
|---|---|
| **Plug-ins** | VST3-плагины с открытым кодом из реестра Nota — см. [Загрузка плагинов](../../plugins/get-plugins/) |
| **Sample Packs** | Бесплатные сэмпл-паки с лицензией для любой музыки — см. [Сэмпл-паки](../../library/sample-packs/) |
| **AI Models** | htdemucs и basic-pitch — см. [ИИ-модели](../../ai/models/) |

<Shot id="preferences/downloads" alt="Settings ▸ Downloads ▸ Plug-ins" />

Всё скачивается из релизов самих авторов, сверяется с зафиксированной контрольной суммой и только
потом распаковывается — установщики не запускаются никогда. Фильтры и поиск остаются наверху при
прокрутке списка. Загрузка продолжается и после закрытия Settings: прогресс переезжает в строку
состояния главного окна, с × для отмены.
