## Sample folders

Папки, которые показывает вкладка браузера **Files** и анализируют
[умные сэмплы](../../library/smart-samples/). Сначала папка одна — `~/Music/Nota Samples`.

- **Add folder…** — выберите одну или несколько папок; папки можно и перетащить из Finder /
  Проводника прямо на список. Папку, которая уже есть в списке или лежит внутри (или снаружи)
  одной из них, Nota не добавит и скажет почему.
- **Set as default** — в папку по умолчанию ставятся [сэмпл-паки](../../library/sample-packs/).
  Она отмечена **default**.
- **Rename…** — имя, которое показывает браузер; папка на диске своё имя сохраняет.
- **Show** — открывает папку в Finder / Проводнике.
- **Remove** — убирает папку из браузера; на диске ничего не меняется. Последнюю папку убрать
  нельзя; если убрать папку по умолчанию, ею после вопроса станет следующая.

Папка на отключённом диске помечается **unavailable** и остаётся в списке. Тот же список можно
менять и из [вкладки Files](../../library/browser/#папки-сэмплов).

## Content folders

- **Projects** — папка, которую показывает вкладка браузера **Projects**. По умолчанию
  `~/Documents/Nota Projects`. **Choose…** выбирает другую папку.

## Version history

**Keep a version history of each project** — каждое сохранение создаёт версию во вкладке History
браузера; версии делят общее аудио, поэтому каждая занимает лишь то, что в ней добавилось. По
умолчанию включено. Выключение **стирает** историю открытого проекта, после предупреждения
(**Turn off and erase**). См. [История версий](../../basics/version-history/).
