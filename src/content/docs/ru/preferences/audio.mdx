Settings открываются через **File ▸ Settings…** или кнопку **Settings** в стартовом окне.

## Аудиоустройство

| Настройка | Что делает |
|---|---|
| **Output** · **Input** | Аудиоустройство, через которое Nota играет и с которого записывает |
| **Sample rate** | По умолчанию устройства, 44 100, 48 000, 88 200 или 96 000 Гц |
| **Buffer size** | По умолчанию устройства, 64, 128, 256, 512, 1024 или 2048 сэмплов |
| **Exclusive mode** (Windows) | Монопольный режим WASAPI — минимальная задержка, но другие приложения замолкают, пока играет Nota |

**Latency** показывает, что значит буфер в миллисекундах. Маленький буфер — меньше задержка между
игрой и звуком (лучше для записи); большой — больше запас процессору (лучше для сведения больших
проектов).

## Test

- **Output check** — **Play test tone**: тихий синус 440 Гц через мастер, чтобы проверить, что Nota
  вообще слышно.
- **Performance** — **CPU check** 5 секунд измеряет нагрузку аудиопотока. Включите проект на
  воспроизведение для реальной цифры: покажет среднее, пик и выпадения.
