Arrangement раскладывает песню слева направо: по строке на трек, время идёт вдоль линейки.
Здесь песня получает окончательную форму.

<Shot id="views/arrangement-timeline" alt="Arrangement со всей демо-песней: группа Rhythm, Keys, Lead и Texture" />

Сверху вниз: полоса **Overview**, дорожка **Sections**, линейка с кнопками **Zoom**, треки и —
закреплённые внизу — треки возвратов и мастер.

## Клипы

Аудиоклипы показывают волну в стиле, выбранном в
[Settings ▸ Appearance ▸ Waveform](../../preferences/appearance/#волна), — по умолчанию
**Smooth**.

| Действие | Результат |
|---|---|
| Двойной щелчок по пустому месту трека инструмента | Создать там MIDI-клип |
| Щелчок по клипу | Выделить его |
| Перетащить клип | Сдвинуть по треку или на другой трек того же типа |
| Перетащить клипы на пустое место под последним треком | Перенести на новый трек — по одному на каждый исходный трек, с тем же инструментом, устройствами и микшером |
| <Kbd>←</Kbd> <Kbd>→</Kbd> | Сдвинуть выделенные клипы на шаг сетки (с <Kbd>⌥</Kbd> — на 1/64) |
| <Kbd>⌥ ↑</Kbd> <Kbd>⌥ ↓</Kbd> | Перенести выделенные клипы на ближайший трек выше или ниже, который их примет, в те же доли |
| Потянуть за левый или правый край | Обрезать клип |
| Перетаскивать с <Kbd>⌥</Kbd> | Игнорировать сетку в этот раз |
| Двойной щелчок по клипу | Открыть в [редакторе клипов](../../editing/piano-roll/) |
| <Kbd>⌘</Kbd>-щелчок | Добавить клип в выделение или убрать из него |
| Протянуть по пустому месту | Выделить все клипы, которых касается прямоугольник |
| <Kbd>⌘ A</Kbd> | Выделить все клипы |

При перетаскивании клипы прилипают к [сетке привязки](../../basics/transport/#сетка-привязки) —
в **Auto** она следует за масштабом, так что клип встаёт на видимые линии, — а края соседних
клипов притягивают его. Кнопка с магнитом (<Kbd>⌘ 4</Kbd>) отключает привязку. Несколько выделенных клипов двигаются вместе, одним шагом отмены.

Пока вы тянете клипы ниже последнего трека, рамка **New track** показывает, куда они лягут.
Когда вы отпустите кнопку, для каждого трека, откуда пришли клипы, появится такой же новый трек
(над возвратами), и клипы переедут на него; одна отмена убирает и то и другое. Стрелки тоже
двигают всё выделение блоком: влево — не дальше начала песни, а <Kbd>⌥ ↑</Kbd> / <Kbd>⌥ ↓</Kbd>
пропускают треки, на которые клипы лечь не могут (аудиоклипы — только на аудиотреки, MIDI-клипы —
на треки инструментов). Каждое нажатие — один шаг отмены.

Правый щелчок по клипу: **Split here**, **Duplicate**, **Delete**, **Deactivate clip**,
**Reverse** (для аудио), **Consolidate**, **Copy** / **Cut** / **Paste**, **Rename…**, **Loop
selection**, **Copy to Session** / **Copy to scene**, а для аудио ещё **Separate stems…** и
**Convert** ([Конвертация аудио в MIDI](../../editing/midi-tools/)). Большинство команд работают
сразу для всего выделения.

<Aside type="tip">
<Kbd>0</Kbd> выключает выделенные клипы: они остаются на месте, серые, и ничего не играют.
Повторное <Kbd>0</Kbd> включает их обратно. Быстрый способ послушать песню без партии.
</Aside>

## Диапазоны времени

<Kbd>⇧</Kbd>-перетаскивание в любом месте дорожек — даже начатое на клипе — выделяет отрезок
времени через несколько треков, а не целые клипы. С диапазоном работают
[Duplicate time, Insert silence, Split и Consolidate](../../editing/time-ranges/), а
<Kbd>⌘ L</Kbd> зацикливает его.

## Навигация

| Действие | Результат |
|---|---|
| <Kbd>⌘</Kbd> + прокрутка | Масштаб вокруг указателя мыши |
| <Kbd>⇧</Kbd> + прокрутка или свайп вбок | Прокрутка вдоль песни |
| Прокрутка | Прокрутка по трекам |
| **Zoom −** / **+** | Отдалить / приблизить |
| Щелчок по линейке | Переставить курсор |
| Протянуть вдоль линейки | Задать диапазон лупа |
| Двойной щелчок по диапазону лупа | Выключить или включить луп; диапазон остаётся |

### Полоса обзора

**Overview** над линейкой показывает всю песню в миниатюре, а видимую часть — окном поверх неё.
Тяните окно вбок — прокрутка, вверх или вниз (или за края) — масштаб; двойной щелчок по полосе
вписывает всю песню в экран. Подпись рядом показывает, какие такты на экране («bar 1–8 / 36»).
**View ▸ Toggle overview** скрывает полосу.

## Секции

Дорожка **Sections** подписывает части песни — Intro, Verse, Drop, — чтобы структура читалась
с первого взгляда.

- Протяните по пустой дорожке, чтобы отметить секцию над этими тактами. Она получит автоматическое имя.
- Щелчок по секции переносит курсор к её началу; двойной щелчок — переименовать.
- Потяните за край секции, чтобы изменить длину, — целыми тактами. Перетаскивание с
  <Kbd>⌥</Kbd> двигает только метку секции, тоже целыми тактами, — музыка под ней остаётся на месте.
- Правый щелчок: **Loop section**, **Select section** (как диапазон через все треки),
  **Duplicate**, **Rename…**, **Reset to default name** и **Delete**. Они меняют только метку.

Каждая такая правка — один шаг отмены. Секции сохраняются вместе с проектом.
**View ▸ Toggle sections** скрывает дорожку.

### Имена секций

Новая секция называется **Section N**, где N — её номер в песне слева направо. Это
*автоматическое* имя: оно пересчитывается, когда вы добавляете, двигаете, дублируете или
удаляете секции. Секции с вашими именами тоже учитываются: если вторая секция называется
«Chorus», третья всё равно остаётся **Section 3**. Своё имя само никогда не меняется.

Двойной щелчок по секции (или правый щелчок ▸ **Rename…**) открывает окошко переименования:

- У автоматической секции окошко открывается пустым, а автоматическое имя показано как подсказка.
  Подпись под окошком — **Automatic name** или **Custom name** — меняется по мере ввода.
- <Kbd>Return</Kbd> сохраняет имя. Это один шаг отмены, а если ничего не изменилось — ни одного.
  Пробелы по краям обрезаются, а пустое имя возвращает автоматическое.
- <Kbd>Esc</Kbd> или щелчок в другом месте отменяет ввод, ничего не меняя.
- **Reset to default** в окошке возвращает секции автоматическое имя. Кнопка доступна только для
  своего имени.

Пункт **Reset to default name** в правом меню секции делает то же самое и неактивен, пока имя уже
автоматическое. С клавиатуры откройте [палитру команд](../../basics/command-palette/) и
выполните **Reset section name**: команда действует на секцию под курсором воспроизведения, а
в строке состояния написано, что произошло.

Отмена и повтор возвращают и имя, и то, было ли оно автоматическим. Секции, названные в прошлых
версиях Nota (в том числе «Section 2»), загружаются как свои имена; сбросьте имя, чтобы секция
снова стала автоматической.

### Перестановка частей песни

Перетащите секцию на другое место — и музыка поедет вместе с ней: все аудио- и MIDI-клипы в её
пределах (клипы, пересекающие её края, режутся по ним), автоматизация на всех треках и на
мастере, лейны дублей. Пока вы тянете, за курсором идёт полупрозрачная копия секции, оранжевая
черта показывает границу между секциями, куда она встанет, а остальные секции уже стоят на
своих будущих местах. Отпустите — секция переедет; отпустите на её же месте или нажмите
<Kbd>Esc</Kbd> — ничего не изменится.

Секции, через которые она прошла, сдвигаются и освобождают место, поэтому длина песни не
меняется, а всё до и после переставленного участка остаётся где было. Чтобы поставить припев
перед куплетом, тяните припев влево, пока его середина не пройдёт середину куплета.

То же самое без перетаскивания — в контекстном меню секции; эти пункты работают с секцией
и всем, что в ней:

| Пункт | Что делает |
|---|---|
| **Move earlier** / **Move later** | Меняет её местами с предыдущей / следующей секцией |
| **Duplicate with content** | Ставит сразу после неё копию вместе с музыкой; остаток песни сдвигается дальше |
| **Delete with content** | Удаляет её вместе с музыкой; остаток песни сдвигается к началу и закрывает пробел |

В палитре команд есть те же четыре действия — **Move section earlier**, **Move section later**,
**Duplicate section with content**, **Delete section with content** — для секции под курсором
воспроизведения. Каждое — один шаг отмены.

<Aside>
Секция, которая перекрывается с другой, не может забрать музыку с собой: непонятно, чья общая
часть. Её перетаскивание двигает только метку, а пункты меню неактивны; сдвиньте край, чтобы
секции не перекрывались.
</Aside>

## Размеры треков

Сделайте треки низкими, чтобы видеть большую песню целиком, или высокими, чтобы работать с
одной партией.

| Что сделать | Зачем |
|---|---|
| Потянуть за нижний край трека (в заголовке или на дорожке) | Сделать его выше или ниже, от 30 до 256 px; размер слегка прилипает к трём пресетам ниже |
| То же, когда выделено несколько треков | Изменить их все вместе |
| <Kbd>⌥</Kbd> + потянуть за нижний край | Изменить высоту всех треков сразу |
| Двойной щелчок по нижнему краю | Вернуть стандартную высоту |
| Правый щелчок по треку ▸ **Track height** | Выбрать **Compact**, **Standard** или **Large** для выделения или для всех треков |
| Потянуть за шов между заголовками треков и дорожками | Расширить или сузить заголовки (160–480 px); двойной щелчок возвращает ширину по умолчанию |

Заголовок показывает то, что помещается. Кнопки — mute, solo, запись и, у аудиотрека, кнопка
мониторинга с наушниками — при любой высоте стоят вместе у правого края, рядом с индикатором
уровня, поэтому не прыгают, когда вы меняете размер трека. У **компактного** трека в одной
строке остаются имя и эти кнопки; громкость, панорама и вход — в [Mixer](../mixer/) и в меню
трека. У **стандартного** — привычные три строки, а вход (или источник MIDI) стоит слева от
строки кнопок. У **большого** кнопки идут под именем, а вход (или источник MIDI), фейдер
громкости и панорама занимают по своей строке, а если трек показывает
[посылы](#посылы-в-заголовках-треков), громкость и панорама делят одну строку. Клипы, волны и
автоматизация растут вместе со строкой.

Строки return-треков и мастера, закреплённые внизу, меняют высоту так же — перетаскиванием
нижнего края или через правый щелчок ▸ **Height** — и по умолчанию **компактные**.
<Kbd>⌘</Kbd>- или <Kbd>⇧</Kbd>-щелчок по return-трекам выделяет несколько, и их высота меняется вместе. У return со
стандартной высоты появляется кнопка mute, у большого — панорама. <Kbd>⌥</Kbd>-перетаскивание
и размеры «для всех треков» их не меняют. Если они заняли бы больше половины аранжировки,
закреплённая часть прокручивается.

Высоты треков, return-треков и мастера и ширина заголовков сохраняются вместе с проектом и не
попадают в историю отмены.

**View ▸ Track headers on the right** ставит список треков справа, так что таймлайн
начинается у левого края, рядом с браузером. Вместе с ним переезжают заголовки return и
master и полоски рядом с Overview, Sections и линейкой. Потяните шов в сторону дорожек,
чтобы расширить заголовки; двойной щелчок возвращает ширину. Тот же выбор — **Settings ▸
Appearance ▸ Track headers** (**Left** / **Right**). Nota запоминает сторону; в проект она
не записывается.

## Посылы в заголовках треков

Трек высоты **Large** (128 px) и выше показывает под громкостью и панорамой свои посылы: по
маленькой ручке на каждый трек возврата, **A**, **B**, … в порядке возвратов, а рядом уровень
(**–**, если посыл выключен). Так можно решить, сколько трека уходит в ревербератор, не открывая
[Mixer](../mixer/). Строка появляется, только когда в проекте есть возвраты; у более низкого
трека посылы остаются в Mixer.

<Shot id="views/arrangement-track-sends" alt="Треки Arrangement высоты Large: под громкостью и панорамой каждого трека ручка посыла A на возврат Reverb" />

| Что сделать | Зачем |
|---|---|
| Потянуть ручку посыла | Задать посыл |
| Навести на неё курсор | Увидеть имя возврата и уровень, например **Send A · Reverb · 35%** |
| Двойной щелчок по ней | Выключить посыл |
| <Kbd>⌥</Kbd>-щелчок по ней | Ввести значение с клавиатуры |

Это тот же уровень, что в Mixer и на карточке Sends трека: подвинули в одном месте — он
сдвинулся везде. В узком заголовке у ручек пропадают буква и уровень — наведите курсор, чтобы
их прочитать.

Движение посыла не попадает в историю отмены, и у посыла нет дорожки автоматизации.

## Имена клипов и группы

Клип показывает имя только там, где начинается серия клипов, поэтому повторяющийся паттерн
читается как один блок; клип, которому вы дали имя вручную, показывает его всегда.
**View ▸ Clip names** переключает: имена на всех клипах, на первом в серии или нигде.

Строка группы — тонкий заголовок с mute, solo и уровнем, который раскрывается до полного
набора, когда группу выбирают; её треки лежат под ним в лотке цвета группы — см.
[Треки](../../basics/tracks/).

## Arrangement и Session вместе

Клипы переносятся между Arrangement и [Session](../session/) через буфер обмена или
<Kbd>⌘ ⇧ C</Kbd> — см. [Копирование, вставка и перетаскивание](../../editing/clipboard/). Пока
трек играет клипы Session, его клипы в Arrangement ждут; **Back to Arrangement** в панели Session
возвращает треки обратно.
