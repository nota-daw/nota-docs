Новая версия Nota выходит примерно раз в неделю. У каждой список изменений есть в трёх местах:

- **В приложении** — после обновления окно **What's New** показывает всё, что изменилось с вашей
  версии; открыть его можно в любой момент через **Help ▸ What's New**.
- **На GitHub** — каждый релиз со своими заметками и загрузками.
- **В исходниках** — полная история в `CHANGELOG.md`.
