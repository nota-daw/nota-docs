Собственная тема — это один JSON-файл в папке тем (где она лежит и как появляются карточки —
см. [Appearance ▸ Свои темы](../../preferences/appearance/#свои-темы)). Здесь описано, что внутри
файла. Писать его с нуля не нужно: сделайте **Duplicate** темы, похожей на то, что хочется, и
меняйте копию — в ней уже есть все цвета.

```json
{
  "formatVersion": 2,
  "id": "night-shift",
  "name": "Night Shift",
  "kind": "dark",
  "font": { "family": "IBM Plex Sans" },
  "radius": { "scale": 0.5, "steps": { "card": 4 } },
  "colors": {
    "SurfaceAbyss": "#08080A",
    "BgApp": "#0F0F12",
    "…": "по записи на каждый токен"
  }
}
```

## Ключи

| Ключ | Что в нём |
|---|---|
| `formatVersion` | `1` (только цвета), `2` (цвета, а также `font` и `radius`) или `3` (ещё и `font.values`) |
| `id` | То, по чему Nota запоминает ваш выбор: строчные латинские буквы, цифры и одиночные дефисы, например `night-shift`. Не id встроенной темы (`studio-dark`, `studio-light`, `ember-graphite`, `ember-paper`), не `system` и не id другого файла в папке |
| `name` | Имя на карточке, от 1 до 40 символов |
| `kind` | `dark` или `light` — в каком ряду стоит карточка и какое место она может занять в **Follow system** |
| `colors` | По цвету `#RRGGBB` на каждый токен ниже. Несколько токенов могут быть полупрозрачными и принимают `#AARRGGBB` |
| `font` | В формате 2 или 3, необязательно. `{ "family": "<имя шрифта>" }`; в формате 3 можно добавить `"values": "<имя шрифта>"`, и тогда `family` можно опустить |
| `radius` | В формате 2 или 3, необязательно. `{ "scale": …, "steps": { … } }` |

Имя файла может быть любым — Nota смотрит на `id` внутри. Файлы, которые Nota пишет сама
(**Duplicate** или тема, сохранённая ИИ), называются `<id>.json`. Читаются только файлы `.json`
размером до 256 КБ, а незнакомый ключ считается ошибкой — так опечатка не пройдёт незамеченной.

## Цвета

В каждой теме одни и те же 122 токена, по одному на роль, — пропустить токен нельзя. Они
разбиты на группы:

| Группа | Что окрашивает |
|---|---|
| Surfaces | Окно, панели, дорожки, приподнятые и утопленные области |
| Grid + graph lines | Линии долей, тактов и рядов; рамки графиков |
| Text | От заголовков до неактивного текста и подписей осей |
| Borders | Обычные и сильные рамки, швы, линейки |
| Accent | Акцентное семейство — его заменяет ваш [акцентный цвет](../../preferences/appearance/#акцентный-цвет), если это не **Orange** |
| Status | Запись, успех, предупреждение, mute, solo и надписи поверх них |
| Data + modulation | Кривые графиков, модуляция, пороги, маркеры |
| Tinted chrome | Заголовки выбранных и замороженных треков, оттенок mute, вуаль за диалогами, подсказки |
| Wells and depth | Дорожки ручек, канавки, секции и заголовки устройств, фаски |
| Piano keys | Белые и чёрные клавиши, полные и мини |
| Track palette | Девять цветов треков, мастер и два возврата |
| Track-shade mix targets | К чему подмешивается цвет трека для светлых и тёмных оттенков |
| Fluent accent ramp | Акцент для стандартных элементов управления |
| Shadows | Тени фасок, всплывающих окон и диалогов — полупрозрачные |

В файле токены идут в этом порядке. ИИ-ассистент, подключённый к Nota, выдаст полный список с
назначением каждого (`get_theme_catalogue`, см. [Управление через MCP](../../ai/mcp/#создать-тему)).

## Шрифт

`font.family` заменяет Geist, собственный шрифт Nota, во всём тексте Nota — меню, панелях,
карточках устройств, piano roll — с теми же размерами и начертаниями. Укажите имя установленного
шрифта так, как его показывает система, например `Helvetica Neue` или `Segoe UI`. Иконки, окна
плагинов и [Nota Remote](../../control/nota-remote/) остаются как есть.

Шрифт, которого нет на этом компьютере, — не ошибка: Nota возьмёт Geist, а карточка об этом
предупредит. Без `font` тема использует Geist.

`font.values` (формат 3) — шрифт для значений и показаний: темпа, позиции, dB, Hz, счётчиков.
Без него значения набраны Geist в новом виде и Geist Mono в
[классическом](../../preferences/appearance/#классический-вид). Если шрифта значений нет на
компьютере, это тоже предупреждение, и используется шрифт самого вида.

```json
"font": { "family": "IBM Plex Sans", "values": "IBM Plex Mono" }
```

## Углы

`radius.scale` умножает все скруглённые углы Nota: `1` — как задумано дизайном (по умолчанию),
`0` делает всё квадратным, `2` — вдвое круглее. Подойдёт любое значение от 0 до 2.

`radius.steps` задаёт отдельные ступени шкалы скруглений точно, в пикселях от 0 до 24, и для своей
ступени главнее `scale`:

| Ступень | По дизайну, px | Где |
|---|---|---|
| `card` | 9 | Карточки устройств, группы на панели инструментов, диалоги |
| `group` | 7 | Кнопки-иконки, чипы, группы сегментов, секции устройств, поиск, меню |
| `field` | 6 | Поля, выпадающие списки, клипы, переключатели, подсветка строк |
| `cell` | 5 | Ячейки сегментов, кнопки треков, подсказки, слоты Session |
| `valueBar` | 4 | Полосы значений, слайдеры, колпачки фейдеров |
| `switch` | 3 | Дорожки тумблеров |
| `fine` | 2 | Ручки тумблеров, ноты, столбики на графиках, каналы индикаторов |

Ступень без своего значения — это значение по дизайну, умноженное на `scale` и округлённое до
целых пикселей. Пристыкованные панели в любой теме остаются квадратными.

Тема с ключом `radius` сохраняет свои углы и в
[классическом виде](../../preferences/appearance/#классический-вид). Тема без него получает
там классические углы: 3 px для `card`, `group` и `field`, 2 px для остальных.

## Проверки

Nota проверяет файл темы, когда читает папку. Находки бывают двух видов:

- **Ошибки** — тему нельзя надеть: это не JSON, ключа не хватает или он незнакомый, цвет — не hex,
  нет токена, id занят, `font` или `radius` стоят в формате 1, число вне диапазона. Всё это
  перечисляется под карточками — сразу всё, с токеном или ключом, о котором речь.
- **Предупреждения** — тема загружается, но что-то трудно читать. Nota меряет те же пары, что и в
  своих темах: основной текст на главных поверхностях (контраст от 4.5), более бледный текст (3.0 и
  2.5), яркий акцент на фоне, текст на акценте, mute, solo, записи и цветах треков, а также
  достаточно ли различаются цвета треков — и акцент, mute, solo и запись между собой. Отсутствующий
  шрифт — тоже предупреждение.

<Aside>
Предупреждения — совет, а не правило: тема с парой предупреждений может выглядеть ровно так, как
вы задумали. Наведите курсор на число на карточке — увидите, что именно измерено.
</Aside>
