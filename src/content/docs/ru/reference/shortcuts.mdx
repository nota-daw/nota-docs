Страница собрана из списка на **Settings ▸ Shortcuts**, поэтому они всегда совпадают. Описания
действий — на английском, как в приложении. Сочетания записаны как в macOS: в Windows и Linux
<Kbd keys="⌘" /> — это **Ctrl**, а <Kbd keys="⌥" /> — **Alt**.

## Command palette

| Клавиши | Действие |
|---|---|
| <Kbd keys="⌘ ⇧ P" /> | Open / close the command palette — from any window, even while typing |
| <Kbd keys="↑ ↓" /> · PgUp PgDn | Move through the results |
| <Kbd keys="Return" /> | Apply where the palette was opened (the target shows in the field) |
| ⌘Return | An instrument or instrument preset on a new track · a track: open it in Devices |
| ⌥Return | Replace the selected device instead of inserting after it |
| ⇧Return | Apply and keep the palette open for the next device |
| <Kbd keys="Tab" /> · ⇧Tab | Filter: all · actions · tracks · devices · presets |
| <Kbd keys="> @ + # ~" /> | Type first to filter: actions, tracks, devices, presets, Modular nodes |
| <Kbd keys="Esc" /> | Close and go back where you were |
