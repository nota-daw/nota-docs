## Sample folders

The folders the browser's **Files** tab shows and [Smart samples](../../library/smart-samples/)
analyses. At first there is one, `~/Music/Nota Samples`.

- **Add folder…** — pick one or more folders; you can also drop folders from Finder / Explorer onto
  the list. A folder already in the list, or inside or around one, isn't added (a note says why).
- **Set as default** — the default folder is where [sample packs](../../library/sample-packs/)
  install. It is marked **default**.
- **Rename…** — the name the browser shows; the folder on disk keeps its own.
- **Show** — opens the folder in Finder / Explorer.
- **Remove** — takes the folder out of the browser; nothing on disk changes. The last folder can't
  be removed; removing the default makes the next one the default, after a question.

A folder on a drive that isn't connected is marked **unavailable** and stays in the list. The same
list can be changed from the [Files tab](../../library/browser/#sample-folders).

## Content folders

- **Projects** — the folder the browser's **Projects** tab lists. By default `~/Documents/Nota Projects`.
  **Choose…** picks another folder.

## Version history

**Keep a version history of each project** — every save records a version, listed in the browser's
History tab; versions share their audio, so each costs only what it adds. On by default. Turning it
off **erases** the history of the open project, after a warning (**Turn off and erase**). See
[Version history](../../basics/version-history/).
